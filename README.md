# Hex Solutions

Static portfolio site for Hex the Engineer.

## Deploy

This folder can be deployed as a static site on GitHub Pages, Vercel, Netlify, Cloudflare Pages, or Hostinger.

For Vercel:

1. Import this repository in Vercel.
2. Use the default static-site settings.
3. Deploy from the `main` branch.

For GitHub Pages:

1. In repository settings, open Pages.
2. Set source to deploy from a branch.
3. Choose `main` and `/root`.
4. Save and wait for GitHub to publish the site.
